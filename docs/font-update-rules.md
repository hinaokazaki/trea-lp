サイト全体のロゴ以外のフォントを、添付モックアップ画像の雰囲気に近づけて統一してください。

ロゴ画像はPNGファイルを使用するため、ロゴ部分のフォント設定は不要です。

フォント方針：

- 見出し・セクションタイトル・ヒーローコピー・価格表示など、上品さを出したい部分は「Noto Serif JP」を使用
- ナビゲーション、本文、説明文、ボタン、カード内テキストなど読みやすさを優先する部分は「Noto Sans JP」を使用
- 日本語サイトなので、英字だけでなく日本語表示も自然に見えるように調整してください

具体的に確認してほしい箇所：

- Headerのナビゲーション
- HeroSectionのキャッチコピー・説明文・ボタン
- About / Concept系のカードタイトル・説明文
- Galleryセクションのタイトル・タグ
- Menuセクションのコース名・価格・説明文
- Reservation CTA
- Footer全体

実装方針：

- Next.jsのフォント設定で `Noto Serif JP` と `Noto Sans JP` を読み込む
- Tailwind CSSで使いやすいように `font-serif` / `font-sans`、または独自のfontFamily設定を追加する
- 既存デザインや余白、カラーは大きく変更しない
- 目的はレイアウト変更ではなく、モックアップに近い上品なフォントバランスへ整えること
- ロゴ画像にはフォント指定を適用しない
